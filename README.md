# Izzy's Library (Static)

This is a static, read-only site that loads book data from `data/books.json`.

## Deploy (Netlify)

1) Create a new site in Netlify (import from Git or drag-and-drop the folder).
2) Build settings: no build command, publish directory `.`.
3) Deploy and verify the site.

## Update Data

Edit `data/books.json` and redeploy.
